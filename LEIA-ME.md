# IG Cera Alveolada (app instalável)

## Colocar no GitHub e ativar o site
1. No GitHub, crie um repositório novo (ex.: `cera-alveolada`).
2. Clique em **Add file > Upload files** e envie TODOS estes arquivos na raiz do repositório:
   `index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png`.
3. Vá em **Settings > Pages**. Em *Source* escolha **Deploy from a branch**, branch **main**, pasta **/ (root)** e salve.
4. Em 1 a 2 minutos o endereço aparece: `https://SEU-USUARIO.github.io/cera-alveolada/`

## Instalar no tablet ou celular
- **Android (Chrome):** abra o endereço, toque em **Instalar app** (botão no topo) ou no menu ⋮ > *Instalar aplicativo*.
- **iPhone/iPad (Safari):** abra o endereço, toque em **Compartilhar** > **Adicionar à Tela de Início**.

Depois de aberto uma vez com internet, o app abre também sem internet.

## Importante
- Os dados ficam guardados no próprio aparelho. Tablet e celular NÃO compartilham dados entre si: use sempre o mesmo aparelho ou transfira pelo **Backup** (Configurações).
- Gere o backup com frequência e guarde o texto (por exemplo, enviando para você mesmo no WhatsApp).
- Para atualizar o sistema, substitua o `index.html` no GitHub; se mudar a lista de arquivos, aumente o número `ig-cera-v1` no `sw.js`.
